QUANTUM DUAL COMMODITIES R14 LINUX
Release: 2026.09.02-R14
Branch: feature/v34-dual-market-engine

FOCUS:
- Only XAUUSD and CRUDE OIL.
- Both markets are evaluated with the same 30-second microstructure / 1-minute context scalper on two execution venues for direct comparison.
- General Crypto R11 and Twelve Data Forex scanners are NOT started by R14.

EXCHANGE LEG:
- XAUUSD executes as XAUUSDT on Binance USD-M Futures; BUY and SELL.
- CRUDE OIL executes as CLUSDT on Aster / Binance Wallet; BUY ONLY. SELL is hard-disabled.
- Exchange execution uses the maximum leverage allowed by the contract when private leverage-bracket data is available. PAPER reports the leverage source/fallback explicitly.
- 1% margin per trade. Contract LOT_SIZE / MIN_NOTIONAL rules are respected.
- Cost gate includes real bid/ask spread, taker fees and slippage allowance. Gross TP must exceed the configured multiple of total round-trip costs.

FOREX / MT5 LEG:
- MT5 bridge auto-detects the broker's XAU symbol and crude symbol (USOIL/XTIUSD/WTI/CL/etc., with Brent patterns lower priority).
- Live broker bid/ask and spread are used on every decision.
- M1 candles plus real broker ticks are used to build 30-second micro-bars.
- PAPER sizing uses the broker's own margin calculator and broker account leverage; PnL is calculated using MT5 order_calc_profit.
- REAL orders, when intentionally enabled by APP_MODE/configuration, are sent through MT5 with native SL/TP.
- CRUDE OIL remains BUY ONLY on MT5 as well.

STRATEGY:
- M1 EMA9/EMA21 + RSI14 + ATR14 context.
- 30s pullback / displacement / flow trigger.
- Spread-aware cost gate before entry.
- Default max holding time 180 seconds.
- The purpose of R14 is comparative PAPER validation: Exchange vs MT5 spread, leverage, WR, net PnL and holding time.

UI R14:
- Futuristic live candlestick chart with 30s / 1m toggle.
- Exchange ↔ MT5 venue selector for the same market.
- Live bid, ask, spread, leverage and current signal diagnostics.
- Entry BUY/SELL markers, exit markers and active Entry / SL / TP horizontal levels directly on the chart.
- Comparison cards and table for XAU Exchange, XAU MT5, Crude Exchange and Crude MT5.

SAFE WEB UPDATE:
- Host-side Quantum Update Agent exposes only status/check/apply over a local Unix socket; Docker socket is NOT mounted into the web application.
- UI can search and apply newer versions without opening a terminal.
- Auto-update checks periodically but will not apply while any tracked commodity position is open.
- The updater refuses a dirty Git working tree and runs Git as the repository owner while privileged deployment is isolated to the update script.
