QUANTUM DUAL V34 LINUX
Release: 2026.08.27-R11
Branch: feature/v34-dual-market-engine
Strategy: R11 Calibrated Sweep/Reclaim/MSS + Pending Retest. M5 handles structure/setup, M15 provides aligned directional bias, and M1 is not used for signal generation. Every Binance symbol is calibrated independently across a 648-combination parameter grid and must survive calibration validation/holdout plus a separate external period after simulated costs before entering the executable whitelist. Entry waits for the calibrated M5 retest; TP1 RR is selected per symbol from 0.45R/0.55R/0.65R/0.75R. Forex removes NAS100, keeps currencies + XAUUSD, calibrates each instrument independently, emits BUY LIMIT / SELL LIMIT Telegram signals before the retest, expires unfilled signals after 3 M5 bars, and tracks WIN/LOSS only after the LIMIT was actually filled. Default Forex polling is 5 minutes. Historical Binance backtest now calibrates only on the 21 days preceding the selected test range, so the user-selected period is fully out-of-sample and includes costs. UI includes detailed Crypto and Forex performance charts with Día/Semana/Mes/Año selectors, pending/filled Forex statistics, model readiness, and R11 model audit in Backtest.
Evidence benchmark (official Binance Data Vision, 20 contracts): R11 found 5 calibratable models; LINKUSDT and ARBUSDT passed the full external gate. LINKUSDT external WR 69.23%; ARBUSDT external WR 72.73%. Weighted external WR across all 5 calibratable models was 65.52% over 58 external trades; only full-gate pass symbols are eligible for automatic execution.
